# 🐱 案例：看筒筒（宠物监控定时汇报）

家里的宠物叫**筒筒**。工作日白天上班时，Agent 每小时自动看一眼它在干嘛——**卧室电脑摄像头 + 客厅小米摄像头**双视角，视觉分析后在家庭群发一张现场照 + 一句唠嗑。

## 效果（真实输出）

> 客厅摄像头刚抓到筒筒啦！尾巴高高竖起、身体舒展，从左边一路小跑到右边，像在巡视自己的领地～运动事件 21:58 触发，几乎是实时的 🐱
> （附客厅照片 + 卧室照片）

## 架构

```
cron（工作日 9/11/13/15/17 点）
  ├─ smart-cam.sh           → 卧室电脑摄像头（PetCam.app 抓帧）
  └─ smart-cam-xiaomi.sh    → 客厅小米摄像头（云回放运动事件）
        ↓
  vision 分析两张图（筒筒在哪/在干嘛）
        ↓
  自然语气汇报 + MEDIA 照片 → 家庭群
```

## 前置条件

1. HA 已部署（docs/01），两路摄像头已接入（docs/02、03）
2. 电脑摄像头抓帧 app（[pet-cam-agent](https://github.com/WeilaiSun/pet-cam-agent) 提供，Swift 零依赖）
3. Agent 支持 cron 定时 + 视觉分析 + 发消息

## cron 任务配置（以 Hermes 为例）

**调度**：`0 9,11,13,15,17 * * 1-5`（工作日 9-17 点整点）

**任务 prompt**（复制给 Agent，`<宠物名>` 替换成你的）：

```
你是宠物监控助手。执行以下两个脚本抓取两个摄像头的画面（脚本输出第一行是图片路径，或输出 ERROR: 开头表示抓帧失败）：

1. bash ~/.hermes/scripts/smart-cam.sh          — 卧室摄像头
2. bash ~/.hermes/scripts/smart-cam-xiaomi.sh    — 客厅小米摄像头（输出含 motion_time 最近运动事件时间）

对拿到的每张图片：
1. 先用 python3 + PIL 转标准 RGB JPEG：python3 -c "from PIL import Image; img = Image.open('<图片路径>'); img.convert('RGB').save('/tmp/cam/convert.jpg', 'JPEG', quality=90)"
2. 再对转换后的图用 vision 分析，用 2-3 句中文描述宠物（<宠物名>）现在在做什么：睡觉/玩耍/吃饭/走动/不在画面里等，顺带描述画面光线和场景。若画面太暗或看不到宠物，如实说明。

语气要求：
- 轻松、随意、可爱，像跟家人说话，不要用"综合判断""数据分析"这类冰冷结构化的词
- 不要列点、不要分条
- 可以用表情符号（🐱😴🏃🍗☀️🌙），但别刷屏
- 两个摄像头都看看，宠物可能在任一地点，也可能两边都没有
- 画面太暗就说"屋里黑乎乎的啥也没看见"，某路摄像头报 ERROR 就叹口气说那路看不到了，别用"错误报告"口吻

【重要】最终回复必须附现场照片：回复开头加 MEDIA: 图片路径（每张独立一行），能拿到几张附几张。即使画面很暗也要附上。
```

## 关键细节

| 细节 | 为什么 |
|---|---|
| PIL 转标准 JPEG | 很多视觉模型不接受任意格式/色彩空间，转 RGB JPEG 最稳 |
| 脚本输出 `ERROR:` 前缀 | Agent 能据此判断哪路摄像头失败，不用猜 |
| 双摄像头互补 | 电脑摄像头看卧室、小米看客厅，宠物可能在任何一边 |
| 运动事件回放 | 纯云摄像头没有实时流，运动事件云回放是最接近"实时"的画面 |

## 扩展玩法

- **运动事件推送**：摄像头属性 `motion_video_time` 刷新时触发推送（比定时更实时）
- **夜间安防**：晚上 11 点后检测到运动 → 告警消息
- **多宠物/多房间**：加更多摄像头脚本，prompt 里列全即可
